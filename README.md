# Parand Khalili — Personal Portfolio (Draft)

A redesigned, lightweight, responsive personal website based on the October 2026 educational CV and publicly visible GitHub repositories. It uses only HTML, CSS, and JavaScript and is compatible with GitHub Pages.

## What's included

- `index.html` — homepage: introduction, research, projects, experience, technical toolkit, contact.
- `projects.html` — filterable list of research, AI, BI, systems, and software projects.
- `style.css` — responsive styling.
- `script.js` — navigation, scroll reveals, project filters, and lightweight network canvas.
- `assets/Parand_Khalili_CV.pdf` — copy of the CV supplied for the redesign.
- `assets/favicon.svg` — custom initial-based favicon.

## Preview locally

In this folder run `python -m http.server 8000`, then open `http://localhost:8000/`.

## Deploy to GitHub Pages

1. Create a backup or separate Git branch for the current `Parand1khalili.github.io` repository.
2. Copy the files in this draft to the repository root (replace old `index.html`, `style.css`, and `projects.html` as needed).
3. Verify GitHub Pages uses `master` branch and the repository root in Settings → Pages.
4. Verify the site and PDF link after publication.
