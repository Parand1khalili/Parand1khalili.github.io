SARA: from graph context to evidence-aware labels

Completed undergraduate experiments, with ongoing thesis interpretation. Graph-aware, risk-aware and evidence-aware LLM pseudo-labeling for graph node classification.

Explore authentic Cora nodes in GraphScope · Inspect frozen results · Sources and boundaries

The research problem

How can a small set of language-model annotations train a useful GCN, and when does graph evidence help or mislead the annotator? Following Chen et al., ICLR 2024, this thesis studies the annotation and label-admission stages. B1 sees target text; Narrative adds recorded local graph context. Both use the same underlying LLM. The downstream GCN already uses structure.

Foundational label-free LLM-GNN paper. B1 is a local paper-inspired baseline, not an exact reproduction of paper B0; FeatProp is not C-Density.

Three methods, distinct contracts

Cora: SARA-Core R1
Frozen risk ranking selects37 of140 annotation targets. KEEP103 unchanged Narrative labels; WITHHOLD37. A two-layer GCN uses CE/noPS, LR0.005. The historical final mean is74.7586%, not the earlier LR0.01 benchmark74.1005%.
Historical cross-dataset R2
An algorithmic policy change, not just a new dataset configuration. PubMed60 removed zero labels; all four Core arms scored78.3288%. CiteSeer did not establish improvement over B1. The separate post-hoc audit found6 jointly wrong PubMed labels and37 in CiteSeer; R2 missed them.
Final PubMed60 / CiteSeer120: R0 + P1
GT-free referral, dependent Blind/Comparison phases, L1 source checks and conservative P1 fusion. These are separate studies from Cora R1. Frozen training precedes isolated GT-only evaluation.

The actual review process

  1. B1 / Narrative frozen pseudo-labels
  2. GT-free R0 referral
  3. Blind review; Comparison only when eligible
  4. L1 schema, quotation and source-identity checks
  5. P1 conservative fusion: admit a label or abstain
  6. Frozen labels and mask; GCN training
  7. Saved predictions; isolated GT-only evaluation

Blind and Comparison use the same provider/model and are dependent phases. L1 is not semantic truth; independent L2 remains NOT_ASSESSED. No example response, node text or source quotation is fabricated here.

Research evolution and decisions

M1–M4: context and prompts
Question: can neighborhood context help text-only annotation? Investigated graph-context representations and prompting. Context can introduce misleading auxiliary evidence; historical exploratory findings are not pooled into the final benchmark.
FeatProp / Narrative
Freeze a selected cohort; compare text-only with graph evidence under matched downstream settings. Decision: separate selection, annotation, filtering and GCN effects.
SARA-2 / SARA-3
Investigate uncertainty referral, blind review, evidence validation and arbitration. Software/fixture success does not establish scientific improvement; exact historical Policy002 details remain partially reconstructed.
SARA-Core R1
Conservative withholding of37 labels instead of automatic correction. Cora's positive exploratory result motivates controlled transfer, not a universal claim.
R2 audit
Joint agreement can hide common errors. No PubMed labels removed; CiteSeer improvement over B1 not established. Decision: report missed jointly wrong cases rather than retune against inspected GT.
R0 / P1 Three-Agent
Use matched-mask E to distinguish correction from coverage. PubMed benefits; CiteSeer suffers more damage than repair. Decision: retain both outcomes and avoid universal Agent claims.

Validity and failure analysis

All results are exploratory and non-independent. Feature-encoder execution provenance is incomplete; historical test outcomes were observed. CiteSeer uses an author-Fixed variant with134 raw/fixed label discrepancies that remain independently unadjudicated. Self-reported confidence is not calibrated correctness. One split per dataset and training-seed SD do not quantify uncertainty over new datasets, splits or independent LLM annotations. L1-valid quotes can still support the wrong primary topic; auxiliary methods and correlated LLM mistakes remain failure modes.
